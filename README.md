### 📂 Projects

#### 1. [Three-Tier CRUD Platform](https://github.com/shaunniee/AWS_3_TIER_CRUD.git)  
AWS EC2 + RDS + S3 + CloudFront platform built with **Terraform**.  
**Highlights:**  
- Multi-AZ deployment with auto-scaling EC2  
- S3 for static assets + CloudFront distribution  
- Infrastructure as Code with Terraform for reproducibility  

#### 2. [Serverless Blog App](https://github.com/shaunniee/AWS_SERVERLESS_BLOG.git)  
Fully serverless blog application using **AWS Lambda, API Gateway, and DynamoDB**.  
**Highlights:**  
- Serverless CRUD operations  
- API Gateway integration with Lambda functions  
- DynamoDB for scalable data storage  

#### 3. [AWS Static Portfolio Website](https://github.com/shaunniee/AWS-PORTFOLIO-WEBSITE.git)  
Static portfolio site hosted on **S3 + CloudFront**.  
**Highlights:**  
- Fast, cost-effective static hosting  
- Global distribution with CloudFront  
- Simple, professional portfolio showcase

#### 4. [Indriya Clinic Website](https://github.com/shaunniee/Indriya-Clinic.git)  
Public web platform for Indriya Clinics (ENT + Psychiatry) **(AWS + REACT.JS)**.  
**Highlights:**  
- Infrastructure as code with Terraform
- Secure static hosting on AWS
- Automated CI/CD with CodePipeline and CodeBuild
- Custom domain with CloudFront, ACM, and Route53

#### 5. [Serverless ordering system](https://github.com/shaunniee/SERVERLESS_ORDERING_SYSTEM)  
A high-throughput, event-driven order processing system built entirely on AWS serverless services. Handles 10,000+ orders/min using the Saga pattern for distributed transactions, with automatic compensation on failure.  
**Highlights:**  
- Infrastructure as code with Terraform
- Saga pattern using Step functions
- Idempotency using Lambda powertools + dynamoDb conditional writes
- Decouppling and shock aborption using SQS queue
